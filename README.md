# YouTube Video Showcase

A simple responsive webpage built using **HTML, CSS, and Bootstrap**.

## Features

* Bootstrap image carousel
* Three YouTube video cards
* Automatic YouTube thumbnails
* "Watch Now" buttons linking to YouTube
* Responsive design for mobile and desktop
* Simple footer with copyright

## Technologies Used

* HTML5
* CSS3
* Bootstrap 5

## Project Structure

```text
my-website/
├── index.html
├── style.css
├── image1.jpg
├── image2.jpg
└── image3.jpg
```

## How to Run

Open `index.html` in any modern web browser.

Make sure the carousel images are placed in the same folder as `index.html`.
